CmdManager

Version __VERSION__ · published __PUBLISHED__

Your library of command-line scripts, synced to every Windows PC you use and put on your PATH.

Requires the .NET 10 Desktop Runtime (x64). Get it from Microsoft: dotnet.microsoft.com/download/dotnet/10.0 (under “.NET Desktop Runtime”, Windows x64). __SETUP_NOTE__

Install CmdManager

  • Requires Windows 10 or 11 (x64) with the .NET 10 Desktop Runtime (x64). The download is about __SIZE_MB__ MB. Without the runtime, CmdManager shows a Windows message with a link to download it.
  • Microsoft Edge opens the installer directly. In other browsers, open the downloaded CmdManager.application file, or use setup.exe instead.
  • CmdManager checks https://cmdmanager.socha3.com/ for updates each time it starts and installs them automatically.
  • The installer is not code-signed yet, so Windows shows "Unknown publisher". Choose Install (or More info → Run anyway for SmartScreen).
